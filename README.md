# Student Study Planner

A command-line application built with Python that helps students organize and track their academic tasks.

## Features

- Add tasks with a course name, description, due date, and priority
- Display tasks sorted by due date
- Mark tasks as completed
- Delete tasks
- Validate dates, priorities, and task-number input
- Save tasks in a JSON file between program sessions

## Technologies Used

- Python
- JSON
- Python datetime module

## How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python3 study_planner.py
